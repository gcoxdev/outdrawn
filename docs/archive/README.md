# Documentation archive

Historical material is retained here for context. These documents describe earlier implementations, measurements, and proposals; their task checkboxes and instructions are not an active work queue. Use [current rules](../current-rules.md) for implemented behavior and [the backlog](../backlog.md) for future work.

- [last-hand-standing/](last-hand-standing/README.md): original rules, card dataset, design specification, prototype plan, and reference images previously stored in the repository root.
- [reports/](reports/): dated project reviews, rules/card audits, simulation reports, and design analyses. Their results describe the code and settings used at the time.
- [superpowers/plans/](superpowers/plans/): historical implementation plans.
- [superpowers/specs/](superpowers/specs/): historical design specifications.

Maintained operational documentation lives under [guides/](../guides/), including [LAN HTTPS hosting](../guides/lan-pwa-https-hosting.md) and [device verification](../guides/device-verification.md).
